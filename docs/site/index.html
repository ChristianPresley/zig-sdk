zig-sdk

zig-sdk is an unofficial SDK for the Model Context Protocol (MCP). It is written in Zig 0.16.0 and has no dependencies. It implements MCP specification revision 2026-07-28.

API reference

The Zig compiler makes these pages from the doc comments of the source code.

  • Module mcp

    The protocol types, the server, the client, the stdio and HTTP transports, authorization and TLS.

  • Module mcp_grpc

    The gRPC transport. It carries JSON-RPC messages over HTTP/2.
